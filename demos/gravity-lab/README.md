# Gravity Lab · 万有引力多体模拟

三维自由空间中的等质量粒子实验。默认采用 **WebGPU 全对直接求和、无碰撞、Plummer 软化引力**；WebGPU 不可用时使用 CPU Float64 直接求和，也可以手动选择 CPU。八叉树引力及对应参数已经移除。碰撞与无碰撞两种模式均固定 **1/60 秒**的 KDK 主步。

粒子半径固定为 0.1、单粒子质量固定为 1，半径与质量分别定义；模型不再使用材料密度常量推导质量。所有粒子同色、同质量，渲染与碰撞共用同一半径。没有墙面、容器、周期边界、合并或额外阻尼；飞离视野的粒子继续参与模拟。作品通过同源 iframe 接入主站，也可独立运行。

实现说明见 [RESEARCH.md](./RESEARCH.md)，功能契约与重构设计见 [ARCHITECTURE-REDESIGN.md](./ARCHITECTURE-REDESIGN.md)。[PERFORMANCE.md](./PERFORMANCE.md) 分别记录本次独立吞吐计时与旧版本历史测量。

## 运行与构建

优先使用仓库根目录已安装的工具链：

```sh
npm install
npm run build:gravity
```

生成的主站资源位于 `public/experiments/gravity-lab/`，不手工维护。主站作品路由为 `/works/gravity-lab`。独立开发可在子项目目录运行：

```sh
cd demos/gravity-lab
npm run dev
```

开发服务为 [http://localhost:4180/](http://localhost:4180/)。单独执行 `npm run build` 输出到本目录 `dist/`。模块、Worker 和 WebGPU 需要通过服务访问，不能直接双击 HTML；WebGPU 的可用性受浏览器、设备及安全上下文影响，参见 [MDN requestAdapter](https://developer.mozilla.org/en-US/docs/Web/API/GPU/requestAdapter)。

## 参数与交互

初始面板使用草稿参数。点击“应用”才替换当前模型；“重新开始”使用上次成功应用的参数，忽略未应用草稿。应用失败保留已有场景。时间倍速与显示设置实时生效。

| 初始参数 | 默认值与范围 |
| --- | --- |
| 种子 | 默认 42，面板最上方常驻；只读小字号数字与刷新图标。影响随机位置及非零初速度 |
| 位置分布 | 默认对称球壳；顺序为均匀球云、均匀球壳、均匀圆盘、对称球壳、对称圆环 |
| 粒子数量 | 默认 384，任意整数 2–20,000；滑杆和数字输入同步，回车或失焦时取整并限制范围，点击“应用”后生效 |
| 初始紧密度 | 默认 0.025，范围 0.005–0.06，步进 0.005 |
| 初始运动强度 Q | 默认 0，范围 0–2，步进 0.05；全部分布均可调整 |
| 引力强度 G | 默认 1，范围 0–10，步进 0.1；0 表示无引力 |
| 计算后端 | 默认 WebGPU，另可选 CPU Float64 直接求和 |
| 碰撞 | 默认关闭，位于初始面板底部 |
| 碰撞关闭：Plummer 软化长度 ε | 默认 1R=0.1，范围 0.1–5R，即 0.01–0.5 |
| 碰撞开启：恢复系数 e | 默认 1，范围 0–1，步进 0.01 |

五种分布的初态均避免球体重叠。随机分布拒绝重叠位置并重新采样；对称分布保留几何对称性，通过最小间距约束确定必要尺度。无法生成有效初态时显示错误，不在播放后偷偷把球推开。

初始运动强度定义为 `Q = 2K / |U_ref|`，其中参考势能始终使用 `G_ref=1` 和当前软化长度。因此实际 G=0 时，非零 Q 仍能生成初速度。初始化保留去除总平动和绕 Y 轴相干转动分量的处理；没有整体旋转、可调半径或可调材料密度参数。

初始紧密度决定球云参考尺度 `R_ref = 0.45 × (N/φ)^(1/3)`，不是材料密度或演化过程中恒定的空间密度。圆盘有有限厚度，随机球壳的球心在同一球面；对称球壳按上下镜像纬线环排列，对称圆环位于 XZ 平面。

- 时间倍速范围 0.1–20×，显示实际推进倍速；算力不足时降低真实推进率，不放大步长或跳过碰撞。
- 空格为模拟页面全局暂停/继续快捷键，焦点在输入框、滑杆、下拉框或按钮上时同样生效，不会同时激活控件；长按只切换一次，输入法组字和 Ctrl/Alt/Meta 组合键不拦截。单步提交一个完整的 1/60 秒主步；隐藏页面停止新推进并清空墙钟积压。
- 拖动旋转、滚轮缩放；触屏单指旋转、双指缩放。首次加载自动聚焦，后续应用/重启保留镜头；手动聚焦显示全部粒子。
- 粒子核心与光晕保留原有近白色，光照在线性 HDR 目标中叠加，再通过四层双向高斯泛光与色调映射显示密集区域的亮核；对降采样层先模糊再合成，避免远景亮斑显出方形纹素。移除随屏幕尺寸额外降低亮度的逻辑，并对小光点抗锯齿；WebGL 不支持浮点渲染时保留直接绘制。
- 轨迹开关显示全部粒子最近64个采样点，至少间隔75毫秒墙钟采样一次；暂停时不重复添加同一步。
- 清晰度有自动、清晰、节能；参数面板可拖动、折叠，“误差”标签页独立显示数值观察。

## 引力与碰撞

关闭碰撞时，完全跳过接触检测和冲量，粒子可以相互穿过：

```text
aᵢ = Gm Σⱼ≠ᵢ (xⱼ−xᵢ) / (|xⱼ−xᵢ|² + ε²)^(3/2)
U  = −Σᵢ<ⱼ Gm² / √(|xⱼ−xᵢ|² + ε²)
```

开启碰撞时 ε=0，使用牛顿引力。KDK 主步的 drift 按连续球体 TOI 处理接触，冲量无摩擦并使用 e；e<1 的真实动能损失单独累计。**步内接触时刻分段不改变1/60秒积分主步，也不增加中间引力更新。** 预算用尽可跨批次续算未提交试算；真正失败回滚整个主步并暂停，不隐式缩步。

CPU CCD 使用保守扫掠候选和事件堆，冲量后重查参与者与全部粒子的接触；候选容量不足改用有界扫描。GPU CCD 在主步开始扫描球对并缓存有限候选；冲量后重查两个参与者与全部粒子，复用其他球对的绝对TOI。双槽候选容量最多262,144项、约8MiB；溢出切换有界全对扫描兜底，不截断接触。当前没有GPU空间网格候选生成，也不按20k粒子的全部球对数量预分配索引/时间数组。

固定步长不保证所有参数下的精度。强引力、密集聚集与频繁接触可能增大积分误差或导致暂停；连续 TOI 只针对 drift 内匀速轨迹，不是连续引力曲线的解析碰撞解。

## 数据流与数值观察

- 主线程持有共享的 GPU device、计算与渲染队列。无碰撞引擎按三个 dispatch 完成 KDK 和活动槽提交；渲染直接读取已提交 GPU 状态，不为每帧画面下载粒子再上传。
- 位置高低位、速度、加速度采用双槽存储；保留补偿求和及位置余量，仍不等于 Float64。
- GPU 轨迹由环形历史缓冲生成。CPU 兼容路径在 Worker 求解，将显示位置单向上传；WebGPU 不可用时延迟加载 WebGL 渲染。
- 设备支持 timestamp-query 时分别采集 GPU 物理与绘制耗时；否则标明队列提交至完成耗时，不把它冒充纯内核耗时。
- 轻量进度与约1秒一次的恢复快照异步读回。误差页可见时，独立 ReferenceWorker 从完整提交快照计算 Float64 势能、动量及最多24个目标的求力 RMS；推进不等待这项诊断。
- 能量漂移使用 `(E + 累计碰撞耗散 − E₀) / max(K₀ + |U₀|, 1e−20)`。基线来自保存的初始已接受状态，不是打开误差页时的运行状态。
- 设备失败恢复最近完整检查点并暂停，随后可点击播放使用 CPU 继续。低频检查点可能损失一段模拟进度，不保证同一步无损恢复。

## 验证与性能边界

本轮完成静态lint、WGSL离线编译和生产构建，并按授权运行独立性能计时。未运行自动测试或产品页面验收；这些检查和吞吐测量不能证明长期数值正确。物理测试已迁移为当前接口，保留供后续明确安排的验证。

独立GPU计时页为开发服务的 `/benchmark-architecture.html`。半径仍为0.25时的三轮无碰撞吞吐中位数：1000粒子54.20×、5000粒子13.70×、20k粒子1.15×；每8步绘制一次且关闭轨迹和运行期诊断，不能当作当前半径配置或产品实际倍速。详细边界与原始数据见性能记录。

显式 CPU 计时入口如下；本轮仅运行1000粒子、120步、三轮的无碰撞配置：

```sh
cd demos/gravity-lab
npm run benchmark:1000
node scripts/benchmark.js --count=20000 --steps=60 --runs=3
node scripts/benchmark.js --count=1000 --steps=60 --runs=3 --collisions
```

脚本计时 CPU 固定步推进，包含首轮求力，不包含渲染和参考诊断；它不测 WebGPU。旧 GPU 基准 HTML/Worker 和旧 `benchmark-1000.js` 已移除，历史 JSON 保留。

GPU 引力仍为 O(N²)。20k粒子每步约4亿次有向相互作用；全轨迹约126万条线段，密集碰撞还增加事件扫描成本。当前不能承诺20k、20×或密集碰撞下的目标帧率，更不能把旧版本测量视作新版成果。
