# 连刃物语 · 第一版

可在电脑与手机浏览器游玩的像素风连线战斗原型。使用 TypeScript 规则核心、Canvas 2D 棋盘和 DOM 操作界面；主角使用用户提供的 Kosuzu 像素动画，以同素材包的 GIF 为姿态与刀光参考，跑动与攻击单独标注运行时长。水果、宝石和出口均使用像素素材，面板、图标与字体采用统一的像素界面，配有路线流光、逐个切开水果和落块动画。

## 运行

在网站仓库根目录使用现有 Node.js 22.13+ 和依赖：

```sh
npm install
npm run dev:chain-game
```

打开开发服务器输出的地址。开发模式仅提供游戏；本地预览始终读取最新文件，不启用离线缓存。

```sh
npm run build:chain-game
npm run build
npm start
```

`build:chain-game` 将游戏单独生成到 `public/games/chain-game/`。网站 `build` 的预构建会同时打包 Gravity Lab 与本游戏，再生成整站静态产物。

本地静态预览默认地址：

- 直接游玩：[http://127.0.0.1:4173/games/chain-game/](http://127.0.0.1:4173/games/chain-game/)
- 网站作品页：[http://127.0.0.1:4173/works/chain-game/](http://127.0.0.1:4173/works/chain-game/)

独立地址可用于主屏幕安装。部署到 HTTPS 后首次联网完整加载并完成资源缓存，即可离线打开。离线脚本只控制 `/games/chain-game/`；线上新版本等待旧游戏页面全部关闭后生效，不在对局中替换代码。localhost、127.0.0.1 和本机 IPv6 地址下的预览不使用离线缓存，更新脚本会立即接管后续请求，但不会自动刷新或清除存档；从旧缓存版本首次升级时，待脚本更新后再刷新页面即可显示最新内容。当前未提供原生安装包。

## 作品名称与封面

作品名称为「连刃物语」，同步用于主站作品卡片、独立游戏页、嵌入试玩页和 PWA 安装名称。作品路由、离线作用域和存档键继续使用 `chain-game`，既有链接与进度无需迁移。

主站封面为 `public/images/chain-game-cover.png`，尺寸 1200 × 900、比例 4:3。封面用真实的 Kosuzu 角色和刀光、水果、宝石、出口及 Fusion Pixel 字体重新合成；不使用 AI 生成素材。源画布为 400 × 300，最终以最近邻放大三倍。运行 `python3 scripts/build-chain-game-cover.py` 可重新生成，需要带 FreeType/WOFF2 支持的 Pillow。

## 操作

- 鼠标左键点击或按住拖拽均可选线，手机同样支持轻点和单指拖拽；从主角开始连接相邻的同种水果，允许斜向连接。按下时不改线，移动超过 6 CSS 像素后从最初按下的位置开始拖拽选线，未拖拽即松开则处理点击。
- 经过宝石后可以切换水果种类；路线允许线段交叉，但不能重复选择同一节点。不可连接的格子不改变当前路线。
- 点击或拖回已选旧节点可缩短路线，点击或拖回主角可清空；当前尾点不操作。松手仅保留路线，不执行回合；合法路线的 GO 在松手瞬间即可按下，无需等待完整伤害、奖励和重力预览。完整回合由独立 Web Worker 计算，结果按 `runId + revision + targets` 缓存；GO 命中缓存时直接提交同一份结果，不会在主线程再次执行一遍规则。Worker 不可用或失败时回退到异步兼容计算，交互与存档格式不变。浏览器 Performance 时间线记录 `chain-game:path-released`、`go-enabled`、`preview-ready`、`commit-ready` 等标记，便于定位后续设备差异。
- 松手后右键、Backspace、Delete 退一步。长按不自动重复撤销；手机通过拖回已选节点回退。
- 松手后，用鼠标左键或手机单指重新按下 GO，立即提交一个回合；棋盘拥有焦点时也可按 Space / Enter。拖线经过 GO 后松手不会执行，尾随点击不会重复提交；键盘和辅助技术的按钮激活继续支持。
- 点击优先编辑路线：可以作为下一步的目标直接选入，包括危险水果、宝石和出口，此时不显示攻击范围。只有不能用于路线编辑的危险水果，点击后才显示攻击范围：普通危险水果攻击上下左右，精英攻击周围八格，以缓慢闪烁的红色方框表示。一次只查看一个水果；点击其他可查看的危险水果切换，点击空白或其他目标关闭。手机采用同样的优先级。
- Tab / Shift+Tab 保留正常焦点导航。
- Esc 或菜单按钮打开菜单。拖动中断、切后台、改变窗口大小均保留最后合法草稿，不自动执行。

GO 按钮内以骷髅图标和数字显示本轮有效连击数 `chainCount`：路线中的每个水果和每个宝石节点各计 1，再加所选连击药水的加成，出口不计数；宝石堆价值不放大连击，例如 9 个水果加一堆价值 2 的宝石仍为 10 连，并达到生成奖励的门槛。实际水果击杀数 `kills` 与关卡击杀进度单独统计，拾取宝石不增加击杀。按本轮预计生成的宝石总颗数，复用棋盘中对应价值的宝石堆图标，放大后铺成按钮背景，没有生成奖励时不显示宝石。这里的颗数表示堆内宝石数量，不是宝石堆的落点数或拾取数量；一堆宝石整体占一个落点。连击数、GO 和空格键帽叠在宝石之上，不显示 `+数值`、宝石数量小指标、外置预览面板或拾取宝石、预计伤害指标。普通危险水果攻击终点的上下左右相邻格，精英还覆盖对角格；同一回合多个攻击者会叠加伤害，路线中已切开的攻击者不会再造成伤害。

棋盘宝石与左上角计数器共用用户提供的浅蓝色像素宝石 `src/assets/ui/gem.png`：价值 1 为一颗、价值 2 为两颗、价值 3 为三颗，价值 5 为分层堆叠的宝石堆。图标数量取代原来的数字面值；选入路线后不显示顺序编号。宝石外观集中在 `presentation/gem-visual.ts`，不参与奖励与拾取判定。

每轮长链奖励保持为一整个 `value=N` 的宝石堆，占一个落点，不拆成 N 个实体。奖励优先砸向随机选中的幸存普通水果，不会砸坏或覆盖精英；没有普通水果时才随机选择空格，没有合法位置则保存在 `pendingDrops`，下轮先处理旧奖励。落点使用独立的 `rewards` 种子随机流，预览不会消耗真实随机状态。砸坏水果计入关卡总击杀与开门进度，不计入本轮连击、连斩加速或奖励门槛，也不递归产宝石；危险水果先结算攻击，再处理奖励，死亡或撤离回合不生成奖励。预览的 `rewardCount` 是实际将落下的各堆 `value` 之和，包含本轮能放下的旧待放置奖励。

游戏界面以大画布为中心：左上以图标和数字显示切开进度及本关已收集的宝石，左下仅居中显示生命图标，右下使用像素字体 GO 按钮，将连击和生成宝石信息直接放在按钮上，并保留空格键帽图标。鼠标、触摸和键盘操作棋盘均不显示画布焦点外框；输入焦点、Tab 导航和棋盘快捷键继续保留。主画面不显示关卡、回合以及“切开”“已收集宝石”“生命”标签。右上角提供三个道具槽，每件护盾或药水独立占一格，同类也不堆叠；帮助和菜单继续保留。桌面和手机均不提供独立的回退、清空或危险范围按钮；宝石库存和关卡选择放在菜单中。

规划中的连线与流动箭头绘制在水果和宝石下方，持续指向终点。沿途不显示节点编号，仅在路线终点水果或宝石上方显示一个大号像素连击数字，与 GO 使用同一有效连击数；每堆宝石计 1，所选连击药水额外加数。终点为门时不在门上显示数字。回退时数字跟随新的尾点，清空路线或开始执行时消失。执行后，主角沿路线依次移动，碰到的水果逐个切开，宝石随经过收集；末刀恢复和终点受击结束后，奖励宝石堆从上方落下、砸碎目标水果，碎块消失后稍作停顿，再让剩余水果和新水果按顺序落入空位。动作播放期间暂时锁定棋盘、菜单和关卡操作，结束后才显示最终棋盘与结算信息。

角色在路线结束后实际受击的瞬间播放低沉撞击音、受击姿态和全屏淡红闪光；约 90 毫秒后，对应生命图标抖动，230 毫秒时碎成像素块并散开消失，留下灰色空心位。一次损失多点生命时从右向左逐颗表现，每次间隔 460 毫秒；护盾挡下的攻击不触发扣血音效、红闪和生命碎裂。致命攻击在最后一段受击动画后继续播放约 720 毫秒死亡表现：角色绕脚下旋转倒地、泛起红色像素尘土并淡出，同时播放独立的下降低鸣与落地闷响。全部受击和死亡反馈完成后才进入奖励下落、补位或复活整备；切后台、中止或减少动态效果会直接收敛到实际剩余生命。动画与声音不修改扣血结果。

成功撤离后不再显示通关弹窗：宝石入库和解锁保存后，第一关直接进入第二关；第二关及之后先展示关间商店，购买或跳过后保存并进入下一关。生命原样继承，只有商店回复商品会回血。生命耗尽同样不会死档：受击动画结束后清空本关随身道具，将生命恢复为 1，并打开与关间商店相同布局的“复活整备”页面；玩家可在该页购买生命和道具、刷新商品，然后重新开始本关或选择任一已解锁关卡。复活整备货架随存档保留，刷新页面不会重抽或重复清空。入场由 `presentation/level-entry-presenter.ts` 播放，约 2.2 秒：水果从画布上方分列错落落下并轻微回弹；带“关卡 N”和骷髅图标、击杀目标数的像素关卡牌随后从上方落入中央，短暂停留后继续向下离场。关卡牌没有按钮，不改变回合与规则状态；入场期间锁定输入，结束后才显示第一关引导。首次进入、菜单换关和重试均播放入场；刷新未行动的关卡只重播动画，不重抽棋盘。切后台、中止或启用减少动态效果时立即结束表现。若刷新时已保存撤离、尚未进入下一关，或正停留在复活整备，则恢复同一货架；第三关之后自动进入确定性生成的第四关，此后持续衔接后续关卡，没有末关。菜单仅显示固定前三关、当前生成关和最高已解锁生成关，不展开无限列表。

## 像素界面与出口

界面使用本地加载的 `ChainPixel` 中文像素字体，来源为 Fusion Pixel 12px 简中版本；正文使用 12 px，较大数字和标题使用原设计像素尺寸的整数倍。字体文件随游戏打包，离线运行不依赖外部字体服务。来源、尺寸与素材维护说明见 [界面资源说明](src/assets/ui/README.md)，字体授权见 [SIL Open Font License](src/assets/ui/LICENSE-OFL.txt)。

HUD、生命、菜单、帮助、退出及键帽图标使用硬边点阵 SVG；棋盘内对应标记使用相同的点阵图形。面板、按钮、菜单、入场关卡牌、失败与教程卡片使用直角边框和硬阴影，不使用圆角和背景模糊。水果及宝石不再绘制背景格子；水果不显示路线选中角框或终点虚线框，危险水果的红色角框及精英金色标记保留，查看危险范围时仍以闪烁红色方框标出受攻击的格子。

出口使用用户提供的 `src/assets/ui/gate.png`。原图保留 100 × 100 像素，绘制时裁去透明边，源区域为 `(1, 9, 98, 78)`；可见门宽精确为三个格子，高度按比例为 `3 × 78 / 98`，约 2.388 格。顶部预留约 2.638 格容纳门，画布比例、绘制位置与指针命中统一由 `presentation/board-geometry.ts` 计算。锁定时门变暗并显示锁图标；合法预览路线拖到门上时，用约 320 毫秒抬起像素锁梁、移开锁体并亮起向上箭头，门恢复亮度。预览从门撤回或清空时反向复锁，快速来回拖动从当前姿态衔接。开锁预览不修改存档，提交撤离时保持开启；已在先前行动实际解锁的门不会因回退重新锁上。减少动态效果时直接切换。门的视觉宽度不改变出口的逻辑格坐标和撤离规则。

## 像素水果与切开效果

用户提供的 12 种独立水果素材全部随项目保存并打包。第一关使用苹果、橙子和黑莓，第二、三关使用橙子、梨、黑莓和苹果；内部 `blue`、`green`、`purple`、`red` 分别对应橙子、梨、黑莓、苹果。苹果复用图集中已有素材，也支持切成两半和被宝石砸碎。读取第一关旧存档时，将原有梨转换为苹果并保留其他进度；第二关已有水果保留，后续补位可随机生成苹果。水果原图、图集和维护说明见 [水果资源说明](src/assets/fruit/README.md)。

命中时直接把真实水果精灵沿切线裁成互补的两半，而非绘制代替水果的碎片。切线随所选招式变化：`melee` 右挥刀以 0 弧度、左挥刀以 π 弧度为基准，`slam` 以 π/2 弧度的竖直斩线为基准，每次切开在 ±30° 内采样一次切线方向；这是表现层随机数，不消耗规则随机数。接触帧两半立即各分离 0.03 格，随后沿切线法线的正反方向慢慢远离，各自最远移动 0.3 个格子，并逐渐淡出；总时长为 30 个 60 FPS 参考帧，即 500 毫秒，播放使用实际经过时间以适应不同刷新率。

奖励宝石复用 `gemClusterPlacements(N)` 的整堆外观，从棋盘上方落到选中的水果格。下落时长为 `min(420, 240 + sqrt(下落格数) × 32)` 毫秒；若另有待放置奖励，各堆相隔 90 毫秒起落。宝石命中与目标水果从显示快照移除发生在同一帧，随后将真实水果图切为最多 16 个 4×4 源像素块，径向飞散、旋转、下坠并淡出，持续 420 毫秒，碎块绘制在宝石下方。所有挥刀产生的 500 毫秒分裂与砸碎效果结束后，再等待 180 毫秒进入原有补位；宝石保持固定，作为分段重力的边界。

## 像素角色

当前主角使用 Kosuzu Sprite Pack，保存全部 136 张独立 PNG，并从待机、跑动、近战、地面重击和受击五组动画整理出 29 张运行帧，打包为单张 512×512 透明图集。近战帧按原图层合成人物与刀光，地面重击使用 `source/slam` 的八张完整 PNG；受击 GIF 的第二个姿态补齐独立 PNG 中缺失的帧。原 PNG、五组参考 GIF、标注与重新打包脚本均随项目保存，不依赖下载目录。角色、水果、宝石、门的图像解码和本地像素字体加载完成后才允许连线执行。

八方向暂用左右朝向占位：向左、向上使用左朝向；向右、向下使用右朝向。斜向根据水平分量决定（左上/左下向左，右上/右下向右），人物保持直立，行动结束后保留最后朝向。每次接近水果时按这一段的移动方向选招：纯上下使用 `slam`，纯左右使用 `melee`（动作接口为 `attack`）；斜向若需要相对当前左右朝向转身，使用 `melee`，无需转身则使用 `slam`。第一段比较执行前保留的朝向，之后逐段更新；经过宝石和出口只移动，也会更新后续选招所比较的朝向。

原近战 GIF 的 11 帧包含两次挥刀；当前只取第 1–5 帧的一次挥击，基础帧时长为 32、44、40、30、34 毫秒，100% 速度下共 180 毫秒。地面 `slam` 保留八张 PNG 姿态，基础帧时长为 16、24、34、30、24、26、22、24 毫秒，100% 速度下共 200 毫秒。每个水果只播放一次所选招式：近战在片段时间 32 毫秒处的第二帧、`slam` 在 40 毫秒处的第三帧与水果切开共用接触标记，人物视觉落点按各自动作的刀刃接触点校正。每次挥击保持自身朝向，完整恢复后衔接下一刀。

每条执行路线重新计算水果连斩速度：前三个水果均为 50%；从第四个起，每多斩一个水果，速度乘以 1.15，最高为 100%。各果速度依次为 50%、50%、50%、57.5%、66.125%、76.04375%、87.4503125%，第八个起封顶。第 `n` 个水果的倍率为 `min(1, 0.5 × 1.15^max(0, n - 3))`。移动、跑动动画时钟、挥击帧与接触标记、命中停顿共用该倍率，不再叠加旧的按路线段缩短位移或最高 1.28 倍攻击加速。100% 速度下单段移动为 104 毫秒，超出一格的距离每格另加 20 毫秒，命中停顿为 18 毫秒，跑动一组为 420 毫秒；实际时长均除以当段倍率。因此前三个水果的直线移动为 208 毫秒，近战为 360 毫秒，`slam` 为 400 毫秒，接触标记与切开同步放慢。移动与等待前一刀恢复仍分别计时。

经过宝石与出口使用跑动，不播放切开动作，不增加或重置水果连斩计数，并继承当前速度。待机、受击、水果切开后的 500 毫秒分离淡出、宝石粒子和掉落补充保持独立时钟。素材没有独立起跑和刹停，直接衔接待机与跑动；最后一刀结束后人物回到逻辑格心，再播放终点回击，随后显示奖励和掉落补充。残影采样已经播放过的人物姿态。

运行时动作接口保留在 `presentation/samurai-sprites.ts`；图集位置、画布锚点、逐帧时长、循环、攻击接触标记和切线基准由 `src/assets/kosuzu/manifest.json` 提供。待机、跑动与受击的画布脚底锚点为 `(16, 64)`，近战为 `(48, 64)`、接触帧刀刃点 `(76, 49)`，`slam` 为 `(64, 64)`、接触帧刀刃点 `(92, 36)`，所有动作保持统一身体尺度。资源来源、时长和维护方式见 [角色资源说明](src/assets/kosuzu/README.md)。

动画只展示已经结算并保存的行动，切到后台或关闭页面不会重复奖励、恢复生命或多走一回合。开始执行、打开菜单或进入新关卡时，关闭当前水果的范围显示；手势取消、指针捕获丢失或失焦不会触发点击选线或范围查看。系统启用“减少动态效果”时，路线保持静态，执行直接展示结算结果，危险范围红框常亮。

## 第一关引导

进入第一关时，尚未跳过或完成引导的档案会自动显示引导；旧存档即使已通关第一关，也能看到新加入的教学。淡金色虚线演示开场十连路线，像素角框指出下一步目标；提示随选线、松手、执行和棋盘变化推进，玩家可以使用其他合法路线。

引导覆盖连接同种水果与回拖、确认执行、十连产宝石、拾取与切换水果种类、累计切开开门、危险水果的攻击范围和连接出口撤离。宝石和危险水果出现后才展示对应提示；危险落点会优先提醒调整，仍由玩家确认行动。中途存档从当前局面接上，不要求重做已经错过的步骤。

“跳过引导”会记住选择，成功撤离后自动完成。引导会自动出现在首次进入的第一关，主界面和菜单不提供重新进入教程关的入口。引导偏好独立保存在 `chain-game:tutorial:v1`，不改变战斗存档或随机数。详见[引导设计](../../docs/chain-game-tutorial.md)。

## 固定关、无限生成关与生命

尺寸按“行 × 列”表示；代码的 `width` 为列数，`height` 为行数。

| 关卡     | 尺寸        | 开门目标   | 初始布局与压力                                               |
| -------- | ----------- | ---------- | ------------------------------------------------------------ |
| 初入矿洞 | 6 行 × 5 列 | 切开 20 个 | 固定布局，包含可选的 10 连；少于 4 连触发愤怒惩罚 |
| 深入矿脉 | 7 行 × 7 列 | 切开 55 个 | 种子随机布局；少于 5 连触发愤怒惩罚                    |
| 精英守门关 | 7 行 × 7 列 | 切开至少 60 个，并击败开场精英 | 沿用第二关的水果和普通愤怒规则，顶部正中固定一个精英水果 |

开门条件按已有总击杀加上当前路线将切开的水果计算；一条路线可以同时达标并连接顶部出口，执行后直接撤离，无需再行动一轮。例如已有 53 / 55 击杀，路线切开 9 个水果后可接入门。第三关同时计入路线击杀的精英，但宝石节点只算连击，不算水果击杀；必须先经过顶部三个入口格之一。仅达标而不接入出口时仍留在棋盘。成功撤离第一关后解锁第二关，成功撤离第二关后解锁第三关，第三关之后进入无限生成流程。生成在棋盘上的宝石要之后实际拾取，撤离时才加入库存；死亡或放弃关卡会失去本局尚未带出的宝石。

固定关与生成关的普通水果开场全部平静。第 N 关的短链门槛为 `min(3 + N, 8)`：有效提交的路线连击小于门槛时，本关累计一次短链行动。前两次各从场上幸存的平静普通水果中随机选 1 个变愤怒，第三次及以后每次选 2 个；候选不足取全部。水果与宝石堆各计 1 连，出口不计；长链不会清零短链累计次数，预览、回退和无效提交不累计。表现层在路线斩击后立即显示变异；核心先结算已有攻击者与扣血，存活时才执行惩罚，再处理奖励和补位，只选择本轮行动前已有的水果。新愤怒从下一轮开始攻击；死亡或撤离后不再执行变异。

累计击杀达到 `goal × max(1 / N, 1 / 10)` 后，每个新补位的普通水果独立以 `1/15` 概率愤怒；第一、二、三关分别在 20、28、20 击杀起启用。随机抽样使用独立的 `rage` 流，不影响水果种类和奖励落点；已愤怒水果保持愤怒。短链累计次数随本局保存，旧存档缺省为 0，不重置棋盘或生命。

第三关开场精英位于门口 `(3, 0)`，始终愤怒，攻击周围八格，每次造成 1 点伤害。它仍遵守同色连接和宝石换色规则，只有在当前路线中成为第 10 个或更后的有效节点时才允许选入并击杀；精英自身计 1 连，每堆宝石计 1 连，不能先选入精英再用后续节点补足门槛。精英不会随重力下落，也不能被奖励宝石砸死。击败开场精英后，本局每次补出新水果时，若场上没有精英，以 1/40 概率将它生成为新精英，同时最多一个；新精英从下一轮开始攻击。首次精英击杀会保存在本局进度，之后的随机精英不会使已满足的开门条件失效。

第四关起使用确定性生成关：完整 7×7 棋盘，按“舒缓 → 标准 → 长链 → 压力 → 守门”五关循环，第 8、13、18……关为守门关。击杀目标随关卡区间和模板在 55～95 内封顶；普通候选预留 4～7 连，长链候选预留 8～12 连（回退布局保留 8 连），守门开局提供到达精英时至少 10 连的合法路线。有限候选、搜索预算和回退布局让生成工作有界；后续回合不保证始终有长链，也不自动洗牌。普通愤怒规则继续按实际 N 计算，没有额外数量上限；守门关的精英仍为 10 连、八邻域和击杀后 1/40 补位规则。

同一世界、同一编号和生成器版本生成相同棋盘；重试不换种子，刷新恢复当前局。生成关 ID 为 `endless-v1-N-seedhex`，本局保存完整 `levelSnapshot`，布局随机流独立于关内补位、愤怒和奖励。具体生成与存档合同见[无限关卡实现](../../docs/chain-game-endless-levels.md)。

**生命跨关卡保留。** 新存档初始 3 点，切关、重试、刷新均不回血。生命归零后不能开局；第二关及之后成功撤离的关间商店可花宝石回复生命，失败后不会另行打开商店。菜单中的“重置全部进度”会要求确认并清空宝石、通关记录和当前对局，再建立全新存档。

奖励档位、愤怒数量和关卡目标是原型调参值，详细规则见 [架构规范](../../docs/chain-game-architecture.md)。

## 关间商店与道具

第一关教程撤离跳过商店；从第二关起，每次成功撤离均先把随身宝石入库，再从八种商品中不重复抽取三种。可购买多项或直接进入下一关，每项在当前货架只能购买一次。花 5 宝石可重新抽取三种并重置本批购买标记；允许再次抽到旧商品，已购道具和效果保留。货架、购买标记与独立随机流保存到会话，刷新页面不会免费重抽。

| 商品 | 价格 | 效果 |
| --- | ---: | --- |
| 回复 1 点生命 | 5 宝石 | 立即回复，最高 3 点 |
| 回复 2 点生命 | 10 宝石 | 立即回复，最高 3 点 |
| 双倍宝石 | 10 宝石 | 紧接着进入的下一局拾取量 ×2，不占道具槽 |
| 护盾 | 25 宝石 | 自动抵挡一次路线结束后的全部攻击，随后销毁 |
| 瞬移药水 | 25 宝石 | 与任意普通水果或宝石交换位置，使用一次后消耗 |
| 连击药水 +3 | 15 宝石 | 下一次执行有效路线增加 3 连击 |
| 连击药水 +5 | 25 宝石 | 下一次执行有效路线增加 5 连击 |
| 连击药水 +10 | 50 宝石 | 下一次执行有效路线增加 10 连击 |

生命回复不占槽；满血时禁用，接近满血时明确显示实际回复量。余额不足、已购买或三格库存已满时，相应购买按钮禁用并说明原因。双倍效果不能重复购买叠加；药水和护盾各占一格，同类也分别占格，未使用的道具跨关、重试、死亡和刷新保留。当前不提供出售或丢弃。

护盾在路线结束受到攻击时自动消耗一个，防住这一轮所有普通与精英水果的攻击；没有攻击或直接撤离则不消耗。多个护盾也只消耗一个，预览不消耗真实库存。触发时播放护盾反馈和金属防御声，不播放红闪或生命碎裂。

点击瞬移药水进入选点，点击普通水果或宝石确认，交换主角与目标实体的位置；精英和门不可选。瞬移不击杀、不拾取、不触发攻击、不推进回合或随机数；确认后清空路线与连击药水选择。再次点击、右键或 Esc 取消不消耗，动画期间不可使用。

点击连击药水可选中或取消，切换另一瓶时替换选择，同一条路线不能叠加多瓶。加成实时用于 GO、终点像素数字、宝石奖励、短链愤怒门槛及到达精英时的前缀连击；不增加实际水果击杀或移动加速。只有执行合法且包含水果或宝石的路线时才消耗；空路线、无效提交和只连接出口不消耗，执行后清除选择。

双倍宝石只在实际拾取时将宝石堆价值乘二，不改变棋盘宝石图标、生成奖励档位或每堆计 1 连击。效果持续下一局，通关、死亡、主动换关或重试后结束；刷新当前局保留，重试不重新发放。撤离按已经翻倍的随身总数入库，不再次翻倍。

盾牌使用用户提供的图标；瞬移药水取逐帧图集第一行，三种连击药水取第六至第八行，其他行忽略。右上角与商店继续使用最近邻像素图标、本地像素字体和硬边面板。完整状态与消费规则见[关间商店与道具](../../docs/chain-game-progression.md)。

## 音效

使用本地 Web Audio 合成短音，参考 Grindstone 的计数、斩击和宝石反馈；当前是合成音色近似，不是参考视频原声。不含背景音乐，也不依赖音频下载：

- 有效加入路线的每个水果或宝石节点播放一次 A“街机快切”计数音，以明亮街机拨弦、上方泛音和低八度芯片音组成五声音阶，随当前有效连击数逐步升高；每个音高档保持相同的包络与噪声形态。一堆宝石只响一次，与堆内价值无关。撤回后重新选择会重新响起；出口、无效连接和回退不发声。
- 每次人物斩击提前约 105ms 启动 A“街机快切”的高速刀风与上升滑音，让短促低频落点和干脆果肉裂响准确落在动作接触帧；slam 音色略低、更厚，连斩加速时音色略微变亮。宝石砸碎水果不触发挥刀声。
- 执行路线经过宝石时，在收集接触点播放清亮的拾取音；每个宝石堆播放一次，不按堆内价值重复。
- 奖励宝石下落抵达落点时，播放带低频撞击的晶体砸地音，与水果被砸碎同步；每堆播放一次，不在下落开始时发声。
- 库存护盾实际挡住整轮攻击时，播放一次短促金属防御声，与终点回击及护盾反馈同步，不按攻击者数量重复。

`presentation/game-audio.ts` 集中管理音色、包络、音量与声部；浏览器首次指针或键盘交互解锁音频。`resume()` 在创建上下文后立即调用，不等待全部音色生成完成；音频硬件恢复后保留约 80ms 预热窗口，第一档计数音使用满增益，避免刷新后第一次手动画线的声音被输出启动吃掉。若上下文仍处于 `suspended`，最多 16 个当次手势产生的短音会排队，恢复后按 10 毫秒间隔补播；超过 750 毫秒的旧请求直接丢弃，避免后续手势突然响出旧音。声音只响应路线编辑及动画中的斩击、拾取和宝石落地事件，不参与规则、存档或随机数。切后台或跳过动画时停止音效，不补播错过的事件。

## 存档

每个已提交回合将当前生命、对局、宝石库存、三格道具和关卡进度保存到同一个本地存档。商店购买、付费刷新、关闭商店、药水选择与瞬移也通过完整会话一次保存；道具操作会更新状态版本但不推进回合，商店库存刷新与网页刷新相互独立。生成关在 `RunState.levelSnapshot` 保存完整关卡定义与 `generation` 版本、世界种子、关卡种子和模板；`getRunLevel` 优先读取快照。会话可选的 `endless` 保存 `worldSeed`、`generatorVersion` 和 `highestUnlocked`，不向固定关通关数组无限追加编号；旧存档缺少这些字段时保留原局，进入生成流程再建立世界信息。第三关同时保存本局精英击杀数 `eliteKills`；旧存档缺少该字段时按 0 处理，不影响已有两关进度。重新载入恢复已提交状态，未执行的草稿不保存。存档只存在当前浏览器，不做账号或跨设备同步。

无法解析的旧存档会保留，当前页面进入临时体验，菜单可以导出原始存档。菜单同时支持导入先前导出的 JSON 存档：读取后先校验版本、规则、棋盘、随机状态和连续性，校验通过才显示覆盖确认；导入失败不会修改当前进度。浏览器禁用保存或写入失败时显示提示，允许导出当前数据。另一个页面已改变存档时，旧页面拒绝覆盖并提示刷新；当前版本不提供多窗口同时操作的事务保证。

| `src/platform/offline.ts`、`public/sw.js`                                   | 隔离范围的离线支持                     |

规则核心不读取 DOM、时钟、存储或全局随机数。相同开局种子、构筑快照和有效命令序列可重现同一结果；预览只计算副本，不消耗真实随机状态。

后续美术可以实现 `ActorVisualFactory`、`ActorVisual`、`EffectsPresenter`、`ScenePresenter`，并替换 `GameRenderer` / `TurnPresenter`。回合事件保留删除前的实体与移动前后坐标，播放时间不参与判定。当前 `AnimatedTurnPresenter` 组合像素人物动作与水果切开反馈，移动、切开和掉落节奏集中在 `motion.ts`，角色片段时长与接触标记集中在 `samurai-sprites.ts`。后台中断或播放异常时直接收敛到已保存的最终状态。

关间商店已经开放生命回复、双倍宝石、护盾和药水。永久装备打造、升级与能力学习仍未开放；固定构筑快照、旧按次抵挡攻击及长链奖励修正接口保留兼容。商品和道具的实际规则见 [关间商店与道具](../../docs/chain-game-progression.md)，基础操作见 [输入交互](../../docs/chain-game-input.md)。
