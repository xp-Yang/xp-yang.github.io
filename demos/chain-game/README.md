# 连锁矿境 · 第一版

可在电脑与手机浏览器游玩的连线战斗原型。使用 TypeScript 规则核心、Canvas 2D 棋盘和 DOM 操作界面；角色、怪物、宝石、出口以几何标记表示，配有路线流光、逐格冲击碎裂和落块动画。

## 运行

在网站仓库根目录使用现有 Node.js 22.13+ 和依赖：

```sh
npm install
npm run dev:chain-game
```

打开开发服务器输出的地址。开发模式仅提供游戏；本地预览始终读取最新文件，不启用离线缓存。

```sh
npm run build:chain-game
npm run build
npm start
```

`build:chain-game` 将游戏单独生成到 `public/games/chain-game/`。网站 `build` 的预构建会同时打包 Gravity Lab 与本游戏，再生成整站静态产物。

本地静态预览默认地址：

- 直接游玩：[http://127.0.0.1:4173/games/chain-game/](http://127.0.0.1:4173/games/chain-game/)
- 网站作品页：[http://127.0.0.1:4173/works/chain-game/](http://127.0.0.1:4173/works/chain-game/)

独立地址可用于主屏幕安装。部署到 HTTPS 后首次联网完整加载并完成资源缓存，即可离线打开。离线脚本只控制 `/games/chain-game/`；线上新版本等待旧游戏页面全部关闭后生效，不在对局中替换代码。localhost、127.0.0.1 和本机 IPv6 地址下的预览不使用离线缓存，更新脚本会立即接管后续请求，但不会自动刷新或清除存档；从旧缓存版本首次升级时，待脚本更新后再刷新页面即可显示最新内容。当前未提供原生安装包。

## 操作

- 鼠标左键点击或按住拖拽均可选线，手机同样支持轻点和单指拖拽；从主角开始连接相邻的同色怪物，允许斜向连接。按下时不改线，移动超过 6 CSS 像素后从最初按下的位置开始拖拽选线，未拖拽即松开则处理点击。
- 经过宝石后可以换色；路线允许线段交叉，但不能重复选择同一节点。不可连接的格子不改变当前路线。
- 点击或拖回已选旧节点可缩短路线，点击或拖回主角可清空；当前尾点不操作。松手仅保留路线，不执行回合。
- 松手后右键、Backspace、Delete 退一步。长按不自动重复撤销；手机通过拖回已选节点回退。
- 点击“执行路线”，或在棋盘拥有焦点时按 Space / Enter，提交一个回合。
- 点击优先编辑路线：可以作为下一步的目标直接选入，包括愤怒方块、宝石和出口，此时不显示攻击范围。只有不能用于路线编辑的愤怒方块，点击后才显示它上下左右的攻击范围，以缓慢闪烁的红色方框表示。一次只查看一个方块；点击其他可查看的愤怒方块切换，点击空白或其他目标关闭。手机采用同样的优先级。
- Tab / Shift+Tab 保留正常焦点导航。
- Esc 或菜单按钮打开菜单。拖动中断、切后台、改变窗口大小均保留最后合法草稿，不自动执行。

预览显示本轮击杀、拾取宝石、新生成宝石和预计伤害。愤怒怪物攻击终点的上下左右相邻格；同一回合多个攻击者会叠加伤害，路线中已击杀的攻击者不会再造成伤害。

棋盘宝石使用与左上角计数器同形的切面图标：价值 1 为一颗、价值 2 为两颗、价值 3 为三颗，价值 5 为分层堆叠的宝石堆。图标数量取代原来的数字面值；选入路线后仍显示路线顺序编号。宝石外观集中在 `presentation/gem-visual.ts`，不参与奖励与拾取判定。

游戏界面以棋盘为中心：左上显示击杀进度和本关已收集的宝石，左下显示生命，右下确认执行路线，规划路线时显示收益与伤害预览。桌面和手机均不提供独立的回退、清空或危险范围按钮；宝石库存和关卡选择放在右上角菜单中。

规划中的连线持续显示向终点流动的光带。执行后，主角沿路线依次移动，碰到的方块逐个碎裂，宝石随经过收集；击杀结束后稍作停顿，剩余方块和新方块按顺序落入空位。动作播放期间暂时锁定棋盘、菜单和关卡操作，结束后才显示最终棋盘与结算信息。

动画只展示已经结算并保存的行动，切到后台或关闭页面不会重复奖励、恢复生命或多走一回合。开始执行、打开菜单或进入新关卡时，关闭当前方块的范围显示；手势取消、指针捕获丢失或失焦不会触发点击选线或范围查看。系统启用“减少动态效果”时，路线保持静态，执行直接展示结算结果，危险范围红框常亮。

## 第一关引导

进入第一关时，尚未跳过或完成引导的档案会自动显示引导；旧存档即使已通关第一关，也能看到新加入的教学。淡金色虚线演示开场十连路线，光圈指出下一步目标；提示随选线、松手、执行和棋盘变化推进，玩家可以使用其他合法路线。

引导覆盖同色连线与回拖、确认执行、十连产宝石、拾取与换色、累计击杀开门、愤怒怪的攻击范围和连接出口撤离。宝石和愤怒怪出现后才展示对应提示；危险落点会优先提醒调整，仍由玩家确认行动。中途存档从当前局面接上，不要求重做已经错过的步骤。

“跳过引导”会记住选择，成功撤离后自动完成。菜单原有的“重看新手引导”可选择在当前棋盘继续，或确认后重开第一关从头学习；从第二关选择“进入教程关”会先说明离关损失，生命和库存继续保留。主界面不增加引导入口。引导偏好独立保存在 `chain-game:tutorial:v1`，不改变战斗存档或随机数。详见[引导设计](../../docs/chain-game-tutorial.md)。

## 两个关卡与生命

尺寸按“行 × 列”表示；代码的 `width` 为列数，`height` 为行数。

| 关卡     | 尺寸        | 开门目标   | 初始布局与压力                                               |
| -------- | ----------- | ---------- | ------------------------------------------------------------ |
| 初入矿洞 | 6 行 × 5 列 | 击杀 20 只 | 固定布局，包含可选的 10 连；开门后的继续行动才开始产生愤怒怪 |
| 深入矿脉 | 7 行 × 7 列 | 击杀 55 只 | 种子随机布局，第 6 回合起每回合新增愤怒怪                    |

达到击杀目标只会打开出口，必须再沿合法路线连接顶部出口并执行撤离才算通关。成功撤离第一关后解锁第二关。生成在棋盘上的宝石要之后实际拾取，撤离时才加入库存；死亡或放弃关卡会失去本局尚未带出的宝石。

**生命跨关卡保留。** 新存档初始 3 点，切关、重试、刷新均不回血。生命归零后不能开局；宝石购买生命属于后续功能，首版暂未实现。菜单中的“重置全部进度”会要求确认并清空宝石、通关记录和当前对局，再建立全新存档。

奖励档位、愤怒数量和关卡目标是原型调参值，详细规则见 [架构规范](../../docs/chain-game-architecture.md)。

## 存档

每个已提交回合将当前生命、对局、宝石库存和关卡进度保存到同一个本地存档。重新载入恢复已提交状态，未执行的草稿不保存。存档只存在当前浏览器，不做账号或跨设备同步。

无法解析的旧存档会保留，当前页面进入临时体验，菜单可以导出原始存档。浏览器禁用保存或写入失败时显示提示，允许导出当前数据。另一个页面已改变存档时，旧页面拒绝覆盖并提示刷新；当前版本不提供多窗口同时操作的事务保证。首版提供导出，不提供导入界面。

## 代码入口与扩展

| 位置                                                                        | 职责                                   |
| --------------------------------------------------------------------------- | -------------------------------------- |
| `src/main.ts`、`src/styles.css`                                             | 页面、菜单、预览、动作确认与会话连接   |
| `src/application/tutorial.ts`、`src/presentation/tutorial-presenter.ts`     | 情境引导、进度偏好、提示卡与目标高亮   |
| `src/core/model.ts`                                                         | 纯数据类型、回合事件与构筑效果快照     |
| `src/core/path.ts`、`src/application/path-editor.ts`                        | 路径合法性、换色和草稿回退             |
| `src/core/turn.ts`                                                          | 同一套预览与执行、奖励、攻击、愤怒     |
| `src/core/board.ts`、`src/core/random.ts`                                   | 开局、下落补怪、分流种子随机数         |
| `src/content/levels.ts`                                                     | 两关配置与教学路线                     |
| `src/application/session.ts`、`src/platform/storage.ts`                     | 生命继承、解锁、幂等入账、保存与校验   |
| `src/presentation/input.ts`                                                 | 鼠标、触摸、键盘与指针中断             |
| `src/presentation/canvas-renderer.ts`                                       | 几何棋盘及统一坐标命中                 |
| `src/presentation/animated-turn-presenter.ts`、`src/presentation/motion.ts` | 回合动画时间线、显示快照与动画节奏参数 |
| `src/presentation/contracts.ts`                                             | 人物、怪物、特效、场景和回合播放接口   |
| `src/platform/offline.ts`、`public/sw.js`                                   | 隔离范围的离线支持                     |

规则核心不读取 DOM、时钟、存储或全局随机数。相同开局种子、构筑快照和有效命令序列可重现同一结果；预览只计算副本，不消耗真实随机状态。

后续美术可以实现 `ActorVisualFactory`、`ActorVisual`、`EffectsPresenter`、`ScenePresenter`，并替换 `GameRenderer` / `TurnPresenter`。回合事件保留删除前的实体与移动前后坐标，播放时间不参与判定。当前 `AnimatedTurnPresenter` 使用几何动画依次呈现这些事件，节奏参数集中在 `motion.ts`，可调整移动、命中、碎裂、落块间隔而不改变规则或存档。后台中断或播放异常时直接收敛到已保存的最终状态。

装备和能力购买界面尚未开放。核心已经保留固定构筑快照、按次抵挡攻击与长链奖励修正接口；未来设计见 [装备与成长](../../docs/chain-game-progression.md)，操作规范见 [输入交互](../../docs/chain-game-input.md)。

## 验证

现有检查入口如下。按当前开发约定，本次动画改动没有新增或运行测试。

```sh
npx tsx --test tests/chain-game-*.test.ts
npm test
npm run build
```

核心与输入用例验证路径、回退、奖励、危险终点、愤怒时序、出口、确定性和指针边界；网站构建额外检查游戏入口、作品页、封面、离线清单和所有被引用资源进入静态产物。手机浏览器兼容性与安装体验仍需真实 iOS / Android 设备试玩验证。
