# 选线、预览与输入交互规范

日期：2026-10-14。本文为第一版的输入实现规范，补充[整体架构](chain-game-architecture.md)，与后续[装备和能力系统](chain-game-progression.md)共用预览及回合结算。

## 1. 依据及证据边界

**用户已明确的需求**：鼠标左键点击或按住并移动均可选择路径；不可连接的节点拖过也没有反应；往回拖可以修改路线；松开左键后，右键点击一次回退一步。移除回退、清空和全局危险范围按钮，改为点击单个愤怒方块查看闪烁红框表示的攻击范围，点击其他地方关闭。点击优先编辑路线：愤怒方块能够作为当前预览路线的下一步时，直接选入路线，不能同时查看它的攻击范围。这些直接作为本项目合同。

## 2. 鼠标操作合同

| 操作 | 路径结果 |
| --- | --- |
| 仅移动鼠标，没有按住左键 | 不追加、不回退路径；可查看悬停信息 |
| 在棋盘按住左键并拖动 | 按下尚不编辑，移动超过 6 CSS 像素后，从原按下点开始采样，逐个尝试连接经过的目标，合法才追加 |
| 左键点击目标，未形成拖拽 | 优先按与拖拽相同的规则编辑路线：主角清空、旧节点截断、当前尾点不操作、合法下一步追加；包括愤怒方块、宝石和出口，不同时查看范围 |
| 点击不能用于路线编辑的愤怒方块 | 显示该方块上下左右的攻击范围；红框缓慢闪烁，一次只显示一个，再点另一可查看的愤怒方块切换 |
| 点击空白或其他不可连接目标 | 关闭范围，草稿不变；普通方块和宝石都不显示范围 |
| 尝试新增异色、非相邻、墙或其他非法目标 | 路径、尾点、颜色锁定和预览保持不变；不出现失败动作、不震动、不改变连线颜色、不自动寻路；已选节点先按回退规则处理 |
| 拖回前一个路径节点 | 删除最后一步，再继续拖动可选择其他分支 |
| 拖到更早的已选节点 | 保留该节点及之前的前缀，删除后续节点；本项目默认 |
| 拖回主角起点 | 清空整个未提交路径；本项目默认 |
| 松开左键 | 保留最后合法草稿，不执行攻击 |
| 左键已松开时点击右键 | 删除最后一个目标节点；空路径时无操作 |
| 右键按住不放 | 不自动重复回退；一次按下至松开最多退一步 |
| 再次按住左键并拖动 | 超过移动阈值后，按第 3 节规则续接、回退或改线 |
| 点击“执行”或按 Space / Enter | 仅在完整路径合法且没有活动拖拽时执行一次回合 |

所有编辑均不扣血、不杀怪、不收集宝石、不耗盾、不推进回合，也不改变真正的随机数状态。已经执行完成的回合不能通过右键撤销。

“无反应”指路径编辑结果完全不变；调试日志可以记录拒绝原因，但正式界面不因每次划过非法格弹提示。指针离开棋盘时保留草稿，回到棋盘仍从最后合法尾点判断下一步。

## 3. 起线、续接与撤销细节

### 起线与再次按下

- 按下时记录原始位置，尚不修改草稿。指针相对原按下点移动超过 6 CSS 像素后才进入画线，并从原按下点开始采样，避免漏掉第一格。
- 空路径时，可以从主角或相邻合法目标开始拖拽；达到移动阈值后按经过顺序选入目标，逻辑起点始终是主角。
- 有草稿时，从当前尾点拖动可以继续；从与尾点相邻的合法新目标拖动可追加一步后继续拖。
- 有草稿时，从路径中的旧节点拖动按同样的前缀截断规则处理；从主角开始拖动清空后可以重画。
- 在无关位置或非法目标按下不清空草稿。该次拖拽进入有效目标后再按现有尾点尝试连接。
- 每次按下都建立新的指针采样起点，不将上一次松开位置到这次按下位置之间的空间当成画过的轨迹。

未达到移动阈值的完整按下、松开手势属于点击，优先调用与拖拽相同的 `editPath` 规则：点击主角清空，点击旧节点截断，点击当前尾点不操作，点击合法下一步追加。合法下一步包括愤怒方块、宝石和出口；路线编辑优先时关闭范围，不显示该愤怒方块的红框。只有不能用于路线编辑的愤怒方块才进入范围查看，显示它上下左右的攻击格；普通方块、宝石没有攻击范围。查看状态最多保存一个方块，点击另一可查看的愤怒方块切换，点击空白或其他目标关闭。范围使用缓慢闪烁的红色方框；系统启用减少动态效果时常亮。手势取消、指针捕获丢失和失焦不能被视为点击，不触发点击选线或范围查看。开始执行、打开菜单或进入新关卡时清空查看状态。

### 回退的单位

“一步”是路径尾部一个节点，包括怪物、宝石，或作为终止节点的出口。若最后选中了出口，第一次回退只移除出口；若最后是宝石，回退移除宝石，不连带删除它之前的怪物。主角起点不在可删除目标列表里。

回退后从保留的路径前缀重新推导颜色状态、拾取、预计奖励、落点攻击、盾牌消耗和最终扣血。棋盘很小，首版直接重新解析整段前缀，避免手动维护多个互相依赖的撤销计数器。

例如 `主角 → 蓝1 → 蓝2 → 宝石 → 绿1`：

1. 右键一次，删除绿1，尾点回到宝石，此时允许从宝石改接另一种颜色。
2. 再右键一次，删除宝石，尾点回到蓝2，颜色重新锁定蓝色。
3. 此时拖到绿色怪物无反应，不能保留已经撤销的换色权限。

点击编辑、连续反向拖拽与连续右键回退调用同一套草稿编辑函数。碰到当前尾点本身无操作；交叉的线段只是图形，不是可以选入或回退的节点。路线允许线段交叉，但不能重复选择同一节点。

访问目标的判断顺序固定为：主角 → 清空；当前尾点 → 无操作；更早已选节点 → 截断；其余新节点 → 校验邻接、颜色和其他规则后追加。回退不得先被“颜色不同”或“与当前尾点不相邻”的新增规则拦截。

## 4. 键盘与手机映射

| 功能 | 电脑 | 手机 |
| --- | --- | --- |
| 选线/改线 | 左键点击或拖拽 | 单指轻点或拖拽 |
| 保留草稿 | 松开左键 | 抬手 |
| 退一步 | 右键、Backspace、Delete；点击或拖回前一节点 | 轻点或拖回前一节点 |
| 清空未提交路径 | 点击或拖回主角 | 轻点或拖回主角 |
| 执行 | Space、Enter 或“执行”按钮 | “执行”按钮 |
| 查看攻击范围 | 左键点击不能用于路线编辑的愤怒方块 | 单指轻点不能用于路线编辑的愤怒方块 |
| 菜单 | Esc 或菜单按钮 | 菜单按钮 |

原图确认了确认、回退、菜单等电脑键位的功能名称。将 Backspace / Delete 也定义成单步回退属于本项目具体映射；本项目通过点击单个愤怒方块查看范围，Tab 保留网页焦点导航。原作的 Tab 查看范围不作为本项目输入映射，WASD / 方向键完整选线方式留到后续校准，首版完整操作以鼠标和触摸为主。

键盘快捷键只在游戏棋盘拥有输入焦点、没有弹窗且不在输入框中时生效；忽略按键自动重复。Space / Enter 不得因长按而在瞬时结算后继续执行第二轮。普通网页按钮保留自己的键盘激活逻辑，不能再被全局监听器重复处理。

界面仅保留独立执行按钮，不提供回退、清空或全局危险范围按钮。回退快捷键和执行命令只在没有活动指针时修改草稿或提交。拖拽中通过反向移动回退；Esc 可结束手势并打开菜单，范围查看只改变显示。所有 HUD 操作均忽略本次画线结束时的尾随合成点击。

Tab / Shift+Tab 在棋盘及其他网页区域均保留正常焦点导航，Esc 打开菜单并转移焦点。恢复焦点不沿用先前按住状态。首版不设置右键长按清空或双击执行等隐藏快捷操作。

手机通过单指轻点或拖动连线，轻点优先编辑路线，只有不能用于路线编辑的愤怒方块才显示范围；不依赖右键或悬停，也不增加额外操作按钮。第二根手指不触发回退、缩放或执行；系统若取消首指，按中断处理。首指仍按住时第二指点“执行”也不提交，必须先结束手势。点击与拖动共用 6 CSS 像素的移动阈值，不使用长按查看。

## 5. 输入状态与模块接口

```text
可编辑（草稿可为空）
  → 左键/首指按下：等待区分点击与拖拽，草稿不变
  → 移动超过 6 CSS 像素：从原按下点采样，进入拖拽
  → 拖拽中合法经过：追加或截断，更新预览
  → 未拖拽即松开：优先编辑路线；无法用于编辑的愤怒方块显示范围，其他目标关闭范围
  → 拖拽松开/系统取消：回到可编辑，保留草稿，不触发额外点击编辑或查看
  → 独立确认：同步锁输入 → 结算 → 展示 → 清空旧草稿
  → 菜单/失焦：暂停输入，保留与棋盘版本一致的草稿
```

当前首版使用同步的 `readonly string[]` 草稿，由 `main.ts` 在回合提交或换关时清空；`presentation/input.ts` 合并管理指针与键盘，区分点击与拖拽手势；点击先按 `editPath(state, targets, edit)` 编辑路线，只有无法用于路线编辑的愤怒目标才显示范围。`editPath` 对非法访问返回原数组，当前尾点的无操作也按路线逻辑处理，不据此显示范围。查看对象仅是界面状态，不写入规则或存档，也不影响预计伤害。没有异步预览，因此无需独立草稿版本。以下版本化结构是未来异步表现或预览的扩展合同，区别于执行回合才改变的 `RunState.revision`：

```ts
type PathNode =
  | { kind: 'entity'; id: EntityId }
  | { kind: 'exit'; id: string };

interface PathDraft {
  runId: string;
  baseRevision: number;
  draftRevision: number;
  targets: readonly PathNode[];
}

type DraftEdit =
  | { type: 'visit'; target: PathNode | { kind: 'player' } }
  | { type: 'undo-one' }
  | { type: 'clear' };

function editPath(
  state: Readonly<RunState>,
  draft: Readonly<PathDraft>,
  edit: DraftEdit,
  context: Readonly<RulesContext>,
): PathDraft;
```

扩展后可以把 `presentation/input.ts` 拆为 `pointer-input.ts` 和 `keyboard-input.ts`；它们与按钮产生同义命令。`application/path-editor.ts` 管理草稿，`core/path.ts` 提供统一的合法性和颜色解析。引入版本化草稿时，`editPath` 拒绝非法访问仍返回原草稿，不增加 `draftRevision`。

合法编辑后调用统一的 `previewPath`，包括盾牌和能力加成。首版最终确认使用 `TurnCommand { runId, revision, targets }`，目标 ID 数组中的 `'exit'` 代表唯一出口。未来异步预览关联 `(runId, baseRevision, draftRevision)`，异步或延迟返回时丢弃旧版本结果，最终确认仍需完整校验。

只把有效提交写入战斗重放日志。指针采样、右键次数和无效拖拽不是战斗随机过程的一部分；如需要调试操作手感，可另存可关闭的输入跟踪记录。

## 6. 浏览器输入边界

1. **单指针所有权**：只由一个活动指针修改草稿；每次移动同时检查该指针和左键/触摸是否仍按住。指针丢失、失焦、`pointercancel` 或捕获丢失时结束手势，保留最后合法前缀，不触发点击编辑或查看。
2. **右键去重**：左键释放且没有活动拖拽时，在一次右键 `pointerdown` 产生一次 `undo-one`；后续 `pointerup`、`click`、`contextmenu` 不重复回退。左键仍按住时忽略右键编辑。
3. **菜单范围**：仅在游戏棋盘区域阻止浏览器右键菜单，不接管整个网站。采用指针事件处理编辑，不再额外用 `mousedown` 同时处理一遍。
4. **确认独立**：只有一次起始于“执行”按钮的独立点击，或无活动拖拽时的新确认按键，才能提交。拖线经过按钮后松手不触发执行；丢弃拖拽尾随的合成点击。确认开始时同步设置提交锁，零动画也不能重复触发。
5. **坐标一致**：命中检测与渲染共用屏幕/棋盘变换。先转换 CSS 像素，再判定节点；不把屏幕像素倍率当格子坐标。缩放、旋转或布局改变时结束当前拖拽，保留有效草稿，避免新旧坐标拼接。
6. **跨区域**：拖出棋盘不会清空或执行；松手在棋盘外也结束拖拽。重新进入后只能从最后合法尾点接邻近目标，不能越过墙或空隙跳格。
7. **生命周期**：切后台先结束输入。回到同一页面时保留草稿；完整重载只恢复已提交状态；重开或 `RunState.revision` 改变时作废旧草稿。

## 7. 快速划动与误选控制

输入采样只恢复玩家实际移动经过的节点，不搜索最佳路径。优先按时间处理浏览器提供的细分采样点；必要时在连续两个采样点间做直线命中检测，按进入节点的先后顺序尝试编辑。

每个格设置适当的中心命中区域，首版可取格宽约 70% 的中心区域作为调参起点。连续停留在同一目标不重复处理；只擦过格角、穿过两条线的交叉点或经过绘制的箭头，不自动选中旁边节点。该尺寸与是否需要少量防抖必须通过真机拖拽验证。

中间出现非法节点时忽略该次访问，后续目标仍必须相对于**当前最后合法尾点**独立校验；不能把非法节点当作新的起点，也不能凭空添加未经过的中转节点。如果后续目标本身不相邻，继续无反应。回到合法邻居后无需松手就能继续画线。

退出画布、松手、中断和重新按下都会打断采样轨迹；不在这类断点之间补线。无法确定真实转弯的稀疏采样不猜测连接次序，宁可停在最后一个合法目标。

## 8. 验收用例

| 场景 | 必须满足的结果 |
| --- | --- |
| 鼠标悬停经过一串同色怪 | 不生成路径 |
| 拖过同色 → 异色 → 不相邻同色 | 只保留前面合法部分；不借异色跳过去 |
| 遇到非法目标后回到合法邻居 | 不松手即可继续连线 |
| 主角 → A → B → C，拖回 B 再到 D | 得到主角 → A → B → D |
| 松开后右键一次，再右键一次 | 每次仅删除尾节点；不清空整条，不撤销战斗 |
| 右键的多种浏览器事件与按住 | 一次按下至松开最多删除一步 |
| 回退经过宝石前后 | 颜色权限、收益、落点危险、盾牌消耗正确重算 |
| 修改到更长/更短链 | 装备和能力预览同步更新，真实次数及收益不变 |
| 松开后重新在尾点或邻居按下 | 正确续接，不连接两次手势之间的空间 |
| 拖线到执行按钮再松手 | 不执行；另一次明确点击才执行 |
| 确认按键长按、按键自动重复、快速双击 | 每次有效独立确认最多结算一轮 |
| 拖拽中右键、第二指、系统取消、切后台 | 不额外回退或执行，草稿保留到最后合法状态 |
| 棋盘缩放或转向后继续 | 新手势坐标正确，旧采样不串入 |
| 已撤离、死亡、动画期间、菜单弹窗 | 禁止编辑或提交战斗路径 |

开发顺序上先完成草稿编辑器的行为用例，再做鼠标和手机输入适配。最终用真实鼠标与手机连续画线、反向改线、松手续接，验证操作手感。
