# 第一关引导系统

第一关的引导随玩家实际操作和当前棋盘推进。教学重点参考 CAPY 制作人公开介绍的[长链奖励、宝石换色、攻击预览和离场决策](https://news.xbox.com/en-us/2023/05/03/grindstone-top-five-survival-tips-for-stonegrinders/amp/)，以下阶段与界面由本项目实现。

## 教学过程

| 阶段         | 出现时机                   | 引导方式                                                                           |
| ------------ | -------------------------- | ---------------------------------------------------------------------------------- |
| 同色连线     | 开场尚未执行               | 从主角出发演示十连虚线，提示八方向相邻与回拖；偏离示范后只提示合法续接，不自动选点 |
| 确认执行     | 规划好路线并松手           | 高亮执行按钮，说明松手只保留草稿；短链同样可以执行                                 |
| 宝石与换色   | 长链奖励出现、路线经过宝石 | 指出实际宝石位置；当前尾点在宝石上时说明可以换色，选入其他颜色后说明继续连接新颜色 |
| 打开出口     | 已完成基础操作             | 高亮左上累计击杀，说明 20 只可以分多次完成                                         |
| 愤怒与落脚点 | 愤怒怪出现或预览有伤害     | 指向可点击查看的愤怒怪，解释红框与攻击叠加；危险落点优先提醒回退调整               |
| 撤离         | 已达标或路线预计能达标     | 高亮入口格和出口；连到出口后高亮执行按钮，说明随身宝石撤离后入库                   |

当前路线预计达成 20 击杀时，也会直接提示连接出口；不要求先执行一轮开门再单独撤离。门上预览开锁、撤回复锁，松手后仍需按 GO 确认。

这些阶段可根据局面跳转。没有产宝石或没有遇到愤怒怪都不妨碍过关；任何合法路线都能执行。第一关少于 4 连的有效行动会累计短链惩罚：前两次各变异 1 个已有平静水果，第三次起各 2 个；新愤怒下一轮才攻击。累计切开达到 20 后，新补位普通水果另有 1/15 概率愤怒；开场普通水果全部平静。引导遇到实际愤怒事件再说明，不人为提前制造危险。点击与拖拽遵循当前输入规则：点击合法目标优先选线，无法用于路线编辑的愤怒怪才能点击查看范围。

## 交互与布局

提示卡位于棋盘外，桌面放在左侧战绩与生命之间，手机竖屏使用固定高度的独立行。提示文字改变、拖拽和动作播放期间都保留卡片占位；示范路线与高亮不参与命中判断。动画播放期间保持原阶段，结束后再显示新棋盘对应的提示。

示范采用淡金色点线与移动光点，真实路线沿用原有连线表现，危险范围保持红色方框。系统减少动态效果时，提示线、光圈与按钮高亮静止。屏幕阅读器只在提示阶段改变时播报正文。

进入第一关时自动开启，是否显示仅依据独立的引导进度，不以关卡通关记录判断。旧存档已通关第一关但未体验过引导时，返回第一关仍会显示；第二关不自动插入教学，也不会强制玩家换关。

引导随时可以跳过；首次引导只在第一关尚未完成或跳过时自动出现，主界面和菜单不提供重新进入教程关的入口。引导偏好独立保存，重开会丢弃本关随身宝石，当前生命与库存保留；保存新关卡失败时不会继续重置引导。

## 实现边界

- `application/tutorial.ts` 根据会话、路径预览、拖拽状态和检查目标生成 `TutorialView`，并在回合动画结束后记录已发生的教学事件。
- `presentation/tutorial-presenter.ts` 维护固定的提示卡节点，`tutorial.css` 负责布局和目标控件高亮。
- `BoardView.tutorial` 仅传入需要高亮的格子与示范点列；Canvas 负责绘制，规则与输入不依赖它。
- 偏好使用独立的 `chain-game:tutorial:v1`，按档案 ID 保存跳过、完成和教学确认。存储不可用时保留内存状态；旧战斗存档无需迁移。
- 新关卡可以扩展阶段选择与提示内容，继续复用同一表现接口。引导不修改随机状态、生命、奖励、路径合法性或出口条件。

本次实现未新增或运行测试。
