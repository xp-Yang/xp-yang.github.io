# 连刃物语：无限关卡实现

日期：2026-10-16。固定前三关保留，从第四关起按需生成后续关卡；不预建无限长数组。

## 玩家流程

成功撤离第三关后自动进入第四关，此后每次撤离继续进入下一关。沿用现有约 2.2 秒的入场表现：水果从上方落下，像素关卡牌显示实际的“关卡 N”和击杀目标。不再使用通关确认弹窗，不增加新的模式入口。

菜单仅列固定前三关、当前生成关与最高已解锁生成关，重复项合并。重试同一世界、同一编号得到同一开局；刷新恢复当前已提交棋盘。更换关卡、重试和继续均不恢复生命。库存宝石、装备及能力跨关保留，本关击杀、随身宝石、短链次数、精英击杀和回合计数在建立新局时重新初始化；未拾取宝石不带入下一关。

## 确定性生成

生成入口根据以下内容建立关卡：

`世界种子 + 实际关卡编号 + 生成器版本 v1 → 模板、击杀目标、开局布局和关卡种子`

生成关 ID 使用 `endless-v1-N-seedhex`，其中 N 为实际关卡编号，最后一段为世界种子的十六进制标识。第 N 关的独立 `stageSeed` 由世界种子与编号派生。初始布局使用独立的 layout 随机流；候选重试不会消费已经进入对局的 `board`、`rage` 或 `rewards` 状态。绘制、音效和路线预览也不消费真实规则随机数。

不根据玩家生命、操作表现或设备速度重新挑选棋盘。同世界、同编号和同版本生成相同关卡；同开局、构筑快照和有效命令顺序重现相同后续结果。

## 五关循环与难度

第四关从舒缓模板开始，每五关循环：

`舒缓 calm → 标准 standard → 长链 long-chain → 压力 pressure → 守门 guardian`

| 模板 | 开局与体验 | 精英 |
| --- | --- | --- |
| 舒缓 | 三种水果，较低击杀目标 | 无 |
| 标准 | 四种水果，常规分布 | 无 |
| 长链 | 预留较长的同色路线 | 无 |
| 压力 | 四种水果，较高击杀目标 | 无 |
| 守门 | 门前精英、精英路线与击杀双目标 | 开场一个 |

守门关出现在第 8、13、18……关。所有生成关均为完整 7 行 × 7 列，出生点在底部正中，门与入口位于顶部中央。使用现有水果、美术、宝石及敌人规则，不引入障碍或新攻击类型。

击杀目标按关卡区间与模板递进，在 55～95 内封顶：4～8 关为 55～65，9～18 关为 60～75，19～38 关为 70～85，39 关以后为 75～95。舒缓取低值，压力和守门取高值。达到平台后主要变化来自布局和模板，攻击伤害、精英门槛和水果种类不无限增加。

普通愤怒规则与固定关完全共用：第 N 关少于 `min(3 + N, 8)` 连触发一次本关短链累计；前两次各随机变异 1 个已有平静普通水果，第三次及以后各 2 个。长链不清零次数；水果和每堆宝石各计 1 连，出口不计。第 5 关起短链门槛封顶 8，不另设普通愤怒数量上限。

累计击杀达到 `goal × max(1 / N, 1 / 10)` 后，新补位普通水果各自以 `1/15` 概率愤怒；第 10 关起激活门槛固定为目标的十分之一。开场普通水果全部平静。惩罚仅抽取路线执行后仍存活的既有普通水果，新变异和新补位愤怒均从下一轮才攻击。核心先处理已有攻击和死亡，再对存活回合执行变异、奖励与补位；死亡或撤离后不追加变异、奖励或补位。

## 有限开局约束

生成器建立候选时先预留可走路线，再平衡其余颜色：普通候选的开局路线为 4～7 个节点，长链候选为 8～12 个节点；普通与长链回退布局保留 8 连。守门模板保证一条真实可选路线，到达精英时至少达到第 10 连；预留路线不重复节点，允许线段自相交，不依赖开局赠送宝石。

颜色分布计入预留路线，避免单种水果几乎占满或缺席。候选按固定顺序处理，最多 24 次尝试，每个候选的路径搜索最多扩展 1600 个节点；未接受候选时使用已知可用回退布局及确定性变体。预算按节点数而非时间计算，手机和电脑不会因性能差异得到不同棋盘。

保证范围是开局预留路线存在，不保证任意后续操作均能无伤过关。不为了当前缺少长链而自动改色、洗牌或降低精英门槛；后续补位继续使用现有随机规则。异形棋盘、障碍、显式卡局重整和完整多回合可解性证明属于后续扩展。

## 精英守门

守门模板沿用固定第三关：门前开场精英固定不下落，攻击周围八格，每次 1 点伤害；只有将精英自身计入后达到至少 10 连才可选入。精英不能被奖励宝石砸死。

至少击败一次精英且总击杀达到本关目标才可开门。若当前路线同时满足条件，可直接连门并在同一轮撤离。首次精英击杀记录不会被后续精英刷新清除。

本局击败首个精英后，场上没有精英时，每个实际补位新水果以 `1/40` 概率成为精英，生成后停止本批其余精英尝试，同时最多一只。普通生成关不启用这一精英刷新规则。精英抽样与普通愤怒 `1/15` 分别处理；新精英下一轮才攻击。

## 关卡读取与存档

`RunState.levelSnapshot?: LevelDefinition` 保存生成关完整定义，包括初始行、目标、颜色、尺寸、出生点、出口、精英策略，以及：

```ts
generation: {
  version: 'v1';
  worldSeed: number;
  stageSeed: number;
  template: string;
}
```

`getRunLevel(state)` 优先读取本局快照，固定老关再查静态目录。路线、战斗、回合和表现都读取同一份关卡定义；解析路线时不生成下一关，不依赖全局可变关卡缓存。恢复已有局时不会因生成器调整而更换目标或棋盘。

会话增加可选的连续进度：

```ts
endless?: {
  worldSeed: number;
  generatorVersion: 'v1';
  highestUnlocked: number;
  lastSettledRunId?: string;
}
```

`getNextSessionLevelId` 提供自动衔接的下一关，`getAvailableEndlessLevelIds` 提供菜单的有限生成关入口。固定前三关继续使用原 ID 与固定通关记录；生成关用最高解锁编号记录进度，避免向 `clearedLevelIds` 无限追加关卡，并用 `lastSettledRunId` 保留当前生成局的一次性结算凭据，不无限追加生成局结算 ID。新局重置当前命令日志，避免跨无限关累计历史。

完整关卡快照、世界信息、最高解锁进度、生命、收益结算及当前局统一写入同一份会话存档。旧存档没有连续进度时沿用原固定关，不重置棋盘、生命或库存；进入生成流程时建立世界种子。刷新已撤离局仍能完成保存后的自动衔接，不重复入库。当前版本使用 v1；未来升级需要保留旧快照和对应版本的重试能力。

## 实现边界

固定前三关的尺寸、目标和精英配置保留；生成关复用核心的连线、换色、奖励、攻击、短链惩罚、补位、出口与生命规则。生成器只负责建立可保存的关卡定义，不承担治疗、装备购买或动态救济。

本次不新增或运行测试、类型检查、lint 或浏览器验收；打包由主任务统一执行。
