# 关间商店、宝石消费与道具

日期：2026-10-16。本文记录当前实现，补充[游戏架构方案](chain-game-architecture.md)。原先的永久装备打造、装备升级与能力学习仍未开放；当前使用关间商店和一次性道具。

## 流程与商品

第一关教程撤离后，宝石入库并直接进入第二关，跳过商店。从第二关起，每次成功撤离均先入库宝石，再展示商店，最后保存下一关并播放原有的关卡牌、水果下落动画。失败、暂停或正在进行关卡时不能购物。

每次从八种商品中不重复随机抽取三种，每个货架上的每项最多购买一次；可购买多项，也可直接继续。

| 商品 | 价格 | 效果 | 占道具栏 |
| --- | ---: | --- | --- |
| 回复 1 点生命 | 5 宝石 | 即时回复 1 点，最高 3 点 | 否 |
| 回复 2 点生命 | 10 宝石 | 即时回复 2 点，最高 3 点 | 否 |
| 双倍宝石 | 10 宝石 | 紧接着进入的下一局拾取宝石数量 ×2 | 否 |
| 护盾 | 25 宝石 | 自动抵挡一次路线结束后的全部攻击，触发后销毁 | 是 |
| 瞬移药水 | 25 宝石 | 选择普通水果或宝石位置瞬移，使用后消耗 | 是 |
| 连击药水 +3 | 15 宝石 | 下一次执行路线的有效连击增加 3 | 是 |
| 连击药水 +5 | 25 宝石 | 下一次执行路线的有效连击增加 5 | 是 |
| 连击药水 +10 | 50 宝石 | 下一次执行路线的有效连击增加 10 | 是 |

刷新固定花费 5 宝石，重新抽取三个互不重复的商品，并清空本批货架购买标记。刷新可以再次抽到旧商品；已购道具、生命与已准备的双倍效果保留。余额足够时可反复刷新，货架采用独立随机流，不影响棋盘、愤怒或奖励。

余额不足、已购买、生命已满、道具栏已满时，对应商品禁用并说明原因。双倍效果已准备时不能重复购买或叠加。回复按实际缺失量封顶：缺 1 点时仍可购买回复 2 点，但商品先显示实际只回复 1 点。

## 三个道具栏

右上角固定展示三个像素道具槽，与帮助和菜单按钮共同排布。每个护盾或药水各占一格，同类道具也分别占格，不叠成一个数量槽；最多同时持有三个。生命回复与双倍效果不占槽。

库存跨关卡、重试、死亡和刷新保留，使用后移除对应一格，后续物品补到前面。没有使用的护盾没有时间限制，也不按新关卡免费重新发放。当前不提供出售、丢弃、合成、装备升级或退款。

图标采用用户提供的盾牌 PNG 与药水逐帧素材，仅使用药水图集第一行的瞬移药水，以及第六至第八行的三种连击药水；其余行忽略。图标以最近邻显示并循环播放，界面保持本地像素字体。

## 护盾

护盾自动触发，不需要主动装备。路线结束后，依据幸存敌人的原位置生成攻击列表；只要存在攻击，消耗一个护盾，抵挡这一轮的全部攻击，包括多个普通愤怒水果与精英水果的同时攻击。即使总伤害超过当前生命，也完整防住这一轮。

没有受到攻击、攻击者已被路线击杀、合法撤离跳过敌袭时均不消耗。持有多个护盾也只用一个；预览只显示结果，不消耗真实库存。库存护盾优先于旧构筑的按敌人抵挡效果，整轮已被护盾抵挡时不扣旧构筑次数。

防御和消耗随回合一起保存；在终点回击时播放一次护盾反馈和金属防御音效，不播放受伤红闪、扣血音效或生命碎裂。切后台、刷新或跳过动画不恢复护盾。

## 瞬移药水

点击药水进入选点模式，棋盘标记可选位置，点击目标确认。再次点击道具、右键或 Esc 取消，不消耗药水。

可选任意普通水果或宝石所在位置。确认后主角移到目标格，目标实体移到主角原位置，保留颜色、价值、愤怒与攻击激活状态。不能选精英水果或门内；当前完整棋盘不提供额外空地落点。

瞬移不击杀、不拾取宝石、不触发连击或敌人攻击，不推进回合或随机数。它作为独立道具操作保存并更新状态版本，使旧路线命令失效；随后清空路线与连击药水选择，从新位置重新规划。斩击、入场等动画期间不可使用。

## 连击药水

点击一瓶连击药水后，选择直接影响预览；再次点击取消，也可切换到另一瓶。一次路线最多使用一瓶，不叠加多瓶。

```text
chainCount = 路线水果节点数 + 路线宝石堆节点数 + 所选药水加成
```

药水只对包含水果或宝石的路线生效。空路线、只连接出口的路线连击为 0，不消耗药水；执行合法且含实体节点的路线时才消耗。无效提交、选择、回退与取消均不消耗；含实体再进入门的合法路线会消耗。执行后清除选择。

加成用于 GO 数字、终点像素数字、宝石奖励档位、短链愤怒惩罚门槛以及到达精英时的连击门槛。例如 7 个有效节点配合 +3 药水达到 10 连击。精英使用到达时已经积累的有效前缀，不能借用后续节点。

药水不增加实际水果击杀和关卡击杀进度，不把宝石堆价值变为更多连击，也不额外播放虚构水果的斩击或使移动加速跳级。宝石砸坏水果仍只计实际击杀，不递归增加连击。

## 双倍宝石与生命

双倍宝石是下一局增益，不进库存。每次拾取宝石堆，按其 `value × 2` 加入随身收益；场上图标与宝石原始价值、奖励生成数量、每堆计 1 连击的规则保持原样。显示快照和拾取音色使用实际获得量，撤离时按已经翻倍的总数入库，不再乘一次。

效果仅作用于紧接着进入的一局，持续整关。通关、死亡、主动换关或重试后结束；重试不会重新获得双倍效果，刷新恢复当前局则保留。死亡或放弃仍失去尚未带出的随身宝石。

新存档初始 3 点生命，跨关、重试和刷新不自动回血。当前只有成功的商店购买恢复生命，上限仍为 3。生命耗尽不能开新局，失败不另弹商店；重置全部进度会连同余额、库存和关卡进度一起清空。

## 保存与代码边界

| 状态 | 保存位置 |
| --- | --- |
| 可花费余额 | `Profile.bankedGems` |
| 生命 | `Profile.health / maxHealth` 与当前 `run.player` |
| 三格库存 | `Profile.inventory` 与 `RunState.inventory` |
| 选中的连击药水 | `RunState.selectedComboIndex` |
| 下一关准备的双倍效果 | `SessionData.nextGemMultiplier` |
| 当前局双倍效果 | `RunState.gemMultiplier` |
| 商店货架、已购项、抽取进度 | `SessionData.shop` |

商店保存关联撤离的 `runId`、下一关 ID、三个商品、已购项、独立随机流、刷新次数和关闭状态。刷新页面继续同一货架，已结算撤离不重复入账。关闭商店进入下一关后不能返回旧商店。

道具选择与瞬移更新对局版本，但不增加 `turn` 或路线行动条数，因此存档允许 `revision >= turn`。旧存档缺少道具与商店字段时保留原进度，不免费发放道具；符合条件的已撤离存档可建立对应货架。未执行的路线草稿仍不保存。

`application/shop.ts` 保存商品与价格；`application/session.ts` 提供 `ensureShop`、`buyShopOffer`、`refreshShop`、`finishShop`、`selectComboItem`、`teleportItem`。界面提交商品 ID 或库存槽位，不决定价格、加成或恢复上限。

购买、刷新、道具操作均先校验，再构造完整新会话，一次保存后才展示成功。保存失败不应用未保存的余额、生命或库存；已有版本冲突保护继续有效，当前不承诺多个窗口同时写入的事务保证。

`core/items.ts` 定义有限道具类型、三格上限与加成解析；`core/path.ts` 同时服务预览和执行；`core/turn.ts` 在独立副本上处理消耗、整轮护盾和收益，预览不消耗真实库存或随机数。旧 `RunState.build`、`equipmentRuntime` 和长链奖励修正保留为存档兼容与扩展接口，商店不销售永久装备或能力等级。
